## 🗂️ Project Overview

**TodoList_Ionic** is a **mobile-ready To-Do List application** built with **Ionic** using Angular.  
It demonstrates core Ionic features such as navigation, UI components, and responsive design for tasks management.

---

## ✨ Features
- 📝 Add new tasks  
- ✔️ Mark tasks as completed  
- 🗑️ Delete tasks  
- 📱 Responsive UI for mobile and web  
- 🔄 Built with reusable Ionic components

## 🚀 Installation & Run (Web / Mobile)
To run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/doaaelomda/TodoList_Ionic


Navigate to the folder

cd TodoList_Ionic


Install dependencies

npm install


Run the app (in browser)

ionic serve


Open your browser at:

http://localhost:8100/

📱 Running on Devices (Optional)

You can build and run on real devices using Capacitor (Android / iOS):

npx cap add android
npx cap add ios

ionic build
npx cap sync
npx cap open android   # or ios

🧠 Notes

This project demonstrates Ionic’s UI framework use (based on Angular) to create mobile-ready hybrid apps using web tech. Ionic includes built-in navigation, components, and UI utilities for a smooth development experience .
